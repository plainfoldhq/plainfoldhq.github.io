Public holidays JSON API (free, no key)

A free JSON file per calendar and year with public holidays, for 26 countries and regions plus five business-day calendars (US federal, Federal Reserve, NYSE, England and Wales, euro T2), 2026-2028. No API key, no sign-up, no rate limit of ours, no tracking: these are plain static files on GitHub Pages, not a server. Licence: CC0-1.0 (public domain dedication).

URLs

https://plainfoldhq.github.io/api/v1/index.json            # list of calendars
https://plainfoldhq.github.io/api/v1/<id>/<year>.json      # one calendar, one year (2026, 2027 or 2028)
https://plainfoldhq.github.io/api/v1/<id>/all.json         # one calendar, all three years

Every file is an object with a meta block (source, licence, API version, years covered, link to the full data) and a holidays array. Each holiday has date (YYYY-MM-DD), name and weekday; some also have name_local (the local-language name), observed_shift (true: a day off in lieu), estimated (true: date not fixed by rule) and weekend (true: falls on a weekend day). index.json lists the calendars with their weekend days and file URLs.

Examples

curl https://plainfoldhq.github.io/api/v1/gb-eng/2027.json
import json, urllib.request
with urllib.request.urlopen("https://plainfoldhq.github.io/api/v1/gb-eng/2027.json") as r:
    data = json.load(r)
for h in data["holidays"]:
    print(h["date"], h["name"])
import requests
data = requests.get("https://plainfoldhq.github.io/api/v1/gb-eng/2027.json", timeout=10).json()
print(len(data["holidays"]), "holidays")
const res = await fetch("https://plainfoldhq.github.io/api/v1/gb-eng/2027.json");
const data = await res.json();
console.log(data.holidays.map(h => h.date + ' ' + h.name));

GitHub Pages serves files with CORS headers that allow browser fetches (check the response headers if you depend on this).

Notes

The five business-day calendars (us-federal, federal-reserve, nyse, uk-england-wales, euro-t2) hold weekday holidays only, as in the Excel holiday lists: a holiday on a Saturday or Sunday is not listed. The 26 regions include weekend holidays (flagged) and days in lieu. Dates come from the open-source holidays package and are checked as described on the public holidays page, which also has the full CSV with every field. Future dates follow current rules; governments can change them.

Stability

v1 paths will not change; years roll forward each November. Files have no authentication and no guaranteed uptime beyond what GitHub Pages offers.
