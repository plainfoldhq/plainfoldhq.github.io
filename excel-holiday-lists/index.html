Holiday lists for Excel NETWORKDAYS and WORKDAY

Excel's NETWORKDAYS counts the working days between two dates, and WORKDAY returns the date a number of working days away. Both take an optional list of holidays as their last argument; without it only weekends are skipped. These are ready-made holiday lists for 2026-2028, as an Excel workbook with the range already named Holidays and as a CSV for Google Sheets.

Copy-paste formulas

=NETWORKDAYS(A2,B2,Holidays)           // working days from A2 to B2, both ends included
=WORKDAY(A2,10,Holidays)                // the date 10 working days after A2 (negative goes back)
=NETWORKDAYS.INTL(A2,B2,1,Holidays)     // same, with a weekend code (see below)
=WORKDAY.INTL(A2,10,1,Holidays)

Excel: download a workbook below, open it and use the name Holidays as in the Example sheet. To use the list in your own workbook, copy the Holidays sheet into it and check (not tested here) that the name Holidays is listed under Formulas > Name Manager (define it there if not), or paste the dates anywhere and refer to that range.

Google Sheets (steps not tested here): download the CSV, then File > Import into a new sheet (or open it and paste the Date column), make sure the dates are real dates (right-aligned), and give the range a name under Data > Named ranges, or use it directly, for example =NETWORKDAYS(A2,B2,Holidays!A2:A40). NETWORKDAYS, WORKDAY and their .INTL versions take the same arguments in Sheets.

The counts are weekday holidays per year. Only weekday holidays are listed: a holiday that falls on a Saturday or Sunday does not change NETWORKDAYS or WORKDAY with the usual Saturday-Sunday weekend, so including it would change nothing. For example the US federal list uses the observed date, so Independence Day 2026 (a Saturday) appears as Friday, July 3, while the Federal Reserve list does not have it. If your weekend is not Saturday and Sunday, use the INTL functions and a list for your own calendar. The dates come from the open-source holidays package, and every date in the files was checked against QuantLib's matching calendar.

NETWORKDAYS.INTL weekend codes

The third argument of NETWORKDAYS.INTL and the third argument of WORKDAY.INTL says which days are the weekend: 1 Saturday and Sunday (the default), 2 Sunday and Monday, 3 Monday and Tuesday, and so on up to 7 Friday and Saturday; 11 Sunday only, 12 Monday only, up to 17 Saturday only. A seven-character text such as "0000011" marks each day from Monday to Sunday (1 = non-working). The holiday range works the same as in NETWORKDAYS. The .INTL functions are not exercised by the tests here.

What was tested

Each workbook's Example sheet holds 61 start/end pairs with NETWORKDAYS and WORKDAY (+10) formulas using the name Holidays. The workbooks were recalculated in LibreOffice Calc and the results compared with numpy's busday_count and busday_offset using the same holiday list. Excel itself was not tested; its NETWORKDAYS and WORKDAY take the same arguments. Other calendars (Germany, France, Australia, Canada, Japan) were left out because the holiday package and QuantLib disagree on bank-holiday and regional dates, and a list nobody can confirm is worse than none.
