US bank (Federal Reserve) holidays for Excel NETWORKDAYS and WORKDAY

28 weekday holidays in 2026-2028 for the US banks (Federal Reserve) calendar (Federal Reserve Bank holidays (a Saturday holiday gets no weekday day off)), ready to use as the holiday range of Excel's NETWORKDAYS and WORKDAY functions. Download the Excel workbook (federal-reserve.xlsx) (the dates are in a sheet named Holidays and a defined name Holidays points at them) or the CSV (federal-reserve.csv) for Google Sheets or any other tool.

Formulas

=NETWORKDAYS(A2,B2,Holidays)    // working days from A2 to B2, both ends included
=WORKDAY(A2,10,Holidays)         // the date 10 working days after A2
=NETWORKDAYS.INTL(A2,B2,1,Holidays)  // same holiday range, weekend code 1 = Saturday and Sunday

With the workbook, Holidays is a workbook-level name, so these work as shown (the Example sheet has them). In another workbook, paste the Date column somewhere and use that range (for example Sheet2!$A$2:$A$40) in place of Holidays, or create the name yourself. Weekday holidays only: a holiday that falls on a Saturday or Sunday does not change NETWORKDAYS or WORKDAY, so it is not in the list (the hub says how the list is built).
